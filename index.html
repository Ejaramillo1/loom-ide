          Using Loom

          Your workspace starts with a blank canvas and an empty Loom folder in Documents. Use File to open a different folder, create files, or save your changes.

          Files open when you choose them. Edits save when you press Save or move to another file. If a file changes elsewhere, Loom keeps your draft and asks you to reopen it before saving.

          Edit acts on the last text field you focused. Standard keyboard shortcuts work directly in text fields.

          Use View to switch workspaces, open panels, and adjust the scene’s appearance. Experiment runs and conversations need a connected Loom server.

          About Loom

          Loom is a human-centered development environment for work, experiments, and collaboration with AI agents.
